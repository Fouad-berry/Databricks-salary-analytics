# Databricks Salary Analytics

Projet Data Lakehouse complet avec Databricks :
- Ingestion (Bronze)
- Nettoyage (Silver)
- Agrégation & Analytics (Gold)
- Prédiction de salaire (ML)

## Structure
```
databricks-salary-analytics/
│
├── notebooks/
│   ├── 01_bronze_ingestion.py
│   ├── 02_silver_cleaning.py
│   ├── 03_gold_aggregation.py
│   ├── 04_salary_prediction.py
│
├── data/
├── README.md
```

## Objectif
Construire un pipeline Data Lakehouse pour l’analyse et la prédiction de salaires.

## Étapes
1. **Bronze** : Ingestion brute des données CSV
2. **Silver** : Nettoyage et typage
3. **Gold** : Agrégations business
4. **ML** : Prédiction de salaire (bonus)
